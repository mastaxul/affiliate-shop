Help ❓

Panduan ringkas menggunakan MastaXul Webmaster Manager.

Google Search Console
1. Tekan Connect Google jika belum connected.

2. Tekan Refresh Properties.

3. Pilih property.

4. Gunakan URL Inspection, Analytics atau Sitemap.
Bing Webmaster
Bing API mempunyai throttle/rate limit.

Site tidak akan dimuat secara automatik ketika page dibuka. Gunakan Load Sites secara manual.
Sitemap
Gunakan URL XML sebenar seperti:

https://www.mastaxul.my/sitemap.xml

Jangan masukkan URL homepage kecuali homepage tersebut memang menghasilkan XML sitemap.
