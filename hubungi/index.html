❓ Help

PASS

Pemeriksaan berjaya dan tiada masalah utama dikesan.

WARNING

Tidak semestinya error, tetapi disarankan diperbaiki.

ERROR

Masalah yang boleh memberi kesan kepada SEO, crawling atau indexing.

INFO

Maklumat tambahan untuk rujukan.

Canonical

URL utama yang memberitahu search engine versi mana yang patut dianggap sebagai URL canonical.

Meta Description

Penerangan ringkas halaman yang boleh digunakan search engine sebagai snippet.

Open Graph

Metadata untuk perkongsian halaman di Facebook dan platform sosial lain.

Noindex

Arahan kepada crawler supaya halaman tidak dimasukkan ke index.

JSON-LD

Structured data dalam format JSON yang membantu search engine memahami kandungan halaman.

Bing OAuth

OAuth membolehkan dashboard berkomunikasi dengan Bing tanpa menyimpan password Microsoft. Token disimpan server-side oleh Worker.
