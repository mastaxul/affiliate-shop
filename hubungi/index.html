📖 Maksud Status

🟢
PASS
Pemeriksaan berjaya dan elemen tersebut berada dalam keadaan baik.
🟡
WARNING
Ada elemen yang belum optimum tetapi biasanya tidak menyebabkan website gagal.
🔴
ERROR
Masalah yang patut diperiksa kerana boleh menjejaskan SEO, indexing atau paparan.
ℹ️
INFO
Maklumat tambahan yang tidak semestinya merupakan masalah.

Canonical

Canonical memberitahu search engine URL utama bagi sesuatu halaman. Ia membantu mengurangkan masalah duplicate content.

Meta Description

Penerangan ringkas halaman yang boleh digunakan search engine untuk membantu menghasilkan snippet.

OG Image

Imej yang digunakan apabila URL dikongsi di Facebook, WhatsApp atau platform sosial yang menyokong Open Graph.

Robots / noindex

Jika halaman mempunyai noindex, search engine diarahkan supaya tidak memasukkan halaman tersebut ke dalam index.

JSON-LD

Data berstruktur yang membantu search engine memahami kandungan seperti Product, Article, Organization dan lain-lain.

HTTP Status

200 biasanya menunjukkan halaman berjaya diakses. 404 bermaksud halaman tidak dijumpai. 500 menunjukkan masalah server.

⚠️ CORS

Versi V3 menggunakan Cloudflare Worker sebagai backend. Ini mengurangkan masalah CORS yang berlaku apabila browser cuba membaca website lain secara terus.
